# The Encoding Effect

A sourced, interactive hypothesis about how screen worlds may become self-relevant, with an evidence ledger and explicit limits.

**Live:** https://aloha-encoding-effect.vercel.app

## Repository contents

`components`, `next.config.js`, `package.json`, `pages`, `public`, `styles`, `vercel.json`

## Local development

```sh
npm ci
npm test
npm run build
```

## Deployment

Deployed on Vercel from `main`. Every push to `main` triggers a production build.
